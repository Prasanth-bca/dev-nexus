# Dev Nexus - Why I'm Building This Project

## Project Vision

**Dev Nexus** is not just a portfolio website.

It is my personal **Developer Automation & Operations Platform** that combines development, automation, infrastructure, and monitoring into one unified application.

The goal is to eliminate the need to switch between multiple tools by providing a single dashboard to manage my entire development workflow.

---

# Why I Started This Project

As a software developer, I work with many different technologies and tools every day.

Examples include:

- n8n
- Inngest
- MongoDB
- Docker
- GitHub
- AWS
- Superset
- ERPNext
- Terminal
- VS Code

Managing these tools separately wastes time and breaks focus.

**Dev Nexus** solves this problem by bringing everything together into one application.
